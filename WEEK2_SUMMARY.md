# Week 2 — Data Structures and Functions

## Concepts covered
- **List:** ordered, mutable collection; useful for a sequence of readings.
- **Tuple:** ordered, immutable collection; useful for fixed values.
- **Dictionary:** key-value mapping; useful for structured records.
- **Set:** collection of unique values; useful for removing duplicates.
- **Functions:** reusable code defined with `def`.
- **Lambda:** small anonymous function, often used as a sorting key.
- **Recursion:** a function calling itself with a base case.
- **List comprehension:** concise way to build a list from an iterable.

## Hands-on work
The script calculates sum of squares, filters values above a threshold, converts temperatures, sorts readings with a lambda, and calculates a recursive sum.

## Client-style mini project
The cleaning functions remove duplicate records, skip missing or invalid temperatures, and reject readings outside a reasonable demonstration range. The range is an example rule and should be changed if a real client defines different validation limits.
