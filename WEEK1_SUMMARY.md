# Week 1 — Introduction to Python Programming

## Concepts covered
- **Variables:** named references used to store values.
- **Data types:** string (`str`), integer (`int`), floating-point (`float`), and Boolean (`bool`).
- **Operators:** arithmetic operators such as `+`, `-`, `*`, and `/`, along with comparison operators used in conditions.
- **Input/output:** `input()` receives user input and `print()` displays results.
- **Conditional statements:** `if`, `elif`, and `else` select actions based on conditions.
- **Loops:** `for` repeats over a sequence; `while` repeats while a condition remains true.
- **Functions:** reusable blocks of code that accept inputs and may return results.
