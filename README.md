# Month 1 Data Science Internship — Completed Work Pack

This pack follows the four-week sequence in the supplied internship brief.

## Contents and order
1. **Week 1 — Python Programming Basics:** variables, data types, operators, input/output, conditions, loops, temperature converter, calculator, and average-temperature processing.
2. **Week 2 — Data Structures and Functions:** lists, tuples, dictionaries, sets, functions, lambda, recursion, comprehensions, transformations, and data cleaning.
3. **Week 3 — NumPy and Pandas:** arrays, operations, broadcasting, Series, DataFrames, indexing, grouping, missing-value handling, and aggregation.
4. **Week 4 — Visualization:** Matplotlib and Seaborn plots plus a feature-relationship dashboard script.

## Run instructions
- Recommended: Python 3.10 or later.
- Install packages: `pip install -r requirements.txt`
- Run scripts from the project root, for example:
  - `python Week1_Python_Basics/week1_python_basics.py`
  - `python Week2_Data_Structures_Functions/week2_data_structures.py`
  - `python Week3_NumPy_Pandas/week3_numpy_pandas.py`
  - `python Week4_Visualization/week4_visualization_dashboard.py`
- The scripts use the included `data/weather_sample.csv` and create outputs under `outputs/`.
- Week 1 includes interactive input prompts. Enter the requested values when prompted.

## Dataset
`data/weather_sample.csv` is a small, clearly labelled demonstration dataset created for this assignment. It intentionally includes a few missing values and a duplicate row so that cleaning operations can be demonstrated. It is not real client or meteorological data.
